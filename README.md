# 💜 Happy Anniversary — 3D Cosmic Love Website

## วิธีใช้งาน
1. เปิดโฟลเดอร์นี้ใน VSCode
2. คลิกขวาที่ `index.html` → เลือก **Open with Live Server** (แนะนำให้ลง extension "Live Server")
   - หรือดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์โดยตรงก็ได้
3. รอฉาก 3D โหลด แล้วลากเมาส์หมุนดูรอบกาแล็กซี คลิกข้อความ/ไอคอนที่ลอยอยู่เพื่อเปิดป๊อบอัปแต่ละอัน

## ไฟล์ที่ควรแก้ไข
- **`config.js`** — จุดเดียวที่ต้องแก้ให้เป็นข้อมูลของคุณ:
  - `relationshipStartDate` วันที่เริ่มความสัมพันธ์ (ใช้คำนวณตัวจับเวลา)
  - `floatingTexts` ข้อความลอยรอบหัวใจ
  - `fortunes` คำทำนายในเกมไพ่
  - `memories` รายการรูป+วันที่+แคปชันความทรงจำ (ใส่ path รูปของคุณเองแทน URL ตัวอย่าง)
  - `puzzleImage` รูปสำหรับต่อจิ๊กซอว์
- **`music.mp3`** — ใส่ไฟล์เพลงชื่อนี้ไว้ในโฟลเดอร์เดียวกับ `index.html` เพื่อให้ปุ่ม 🔊 เปิดเพลงได้ (ตอนนี้ยังไม่มีไฟล์เพลงแนบมาให้ เพราะเป็นเรื่องลิขสิทธิ์เพลง)

## โครงสร้างไฟล์
```
anniversary-site/
├── index.html      ← โครงหน้าเว็บ + modal ทั้งหมด
├── style.css       ← ธีมจักรวาลนีออน + glassmorphism
├── config.js        ← ข้อมูลที่คุณแก้เอง (วันที่, ข้อความ, รูป)
├── script.js       ← Three.js scene, เกม, ระบบ modal
└── music.mp3       ← (คุณเพิ่มเอง) เพลงประกอบ
```

## เทคโนโลยีที่ใช้
- Three.js r128 (โหลดผ่าน CDN, ไม่ต้อง npm install)
- OrbitControls สำหรับหมุนกล้อง 360°
- Vanilla JavaScript ล้วน ไม่มี build step — เปิดไฟล์แล้วรันได้เลย

## ทำอะไรได้บ้างในเว็บนี้
1. 💌 จดหมายถึงเธอ
2. ⏱️ นับเวลาความสัมพันธ์แบบเรียลไทม์ (วัน/ชม./นาที/วิ)
3. 🔮 เกมเสี่ยงไพ่ทำนายความรัก (สุ่มจากรายการใน config.js)
4. 🧩 เกมต่อจิ๊กซอว์แบบเลื่อน (3x3)
5. 📸 การ์ดความทรงจำแบบไทม์ไลน์
6. 🎵 ปุ่มเปิด/ปิดเพลงประกอบ

หากอยากปรับสี ฟอนต์ หรือเพิ่มข้อความ/ไอคอนลอยเพิ่ม แก้ที่ `style.css` (ตัวแปรสี `--purple`, `--pink`) และ `script.js` ฟังก์ชัน `buildFloatingLabels()`
